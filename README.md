# 🧠 Interfaz Web para Psicólogo

Interfaz web desarrollada en React para la gestión de un consultorio psicológico. Forma parte de un proyecto en equipo full-stack, donde esta parte corresponde a la vista del psicólogo.

## 🛠️ Tecnologías utilizadas

- React
- Tailwind CSS
- Vite
- React Router
- Chart.js
- html2canvas / jsPDF

## ✨ Funcionalidades

### Autenticación
- Login con selección de rol (psicólogo / paciente).
- Formulario de registro para nuevos usuarios.

### Panel del Psicólogo
- **Perfil**: foto, nombre, especialidad, correo, teléfono, lugar de atención, edición de perfil y código QR para enlazar pacientes.
- **Pacientes**: lista con nombre, edad, fecha de inicio, diagnóstico y estado (en mejoría, grave, de alta). Incluye eliminar y ver detalles.
- **Agenda**: citas por día con hora, estado, duración y notas. Indicador de citas del día y formulario para crear nuevas citas.
- **Historial clínico**: datos personales, historial médico, diagnóstico, tratamiento, chat y estadísticas.
- **Diagnóstico**: comportamiento, personalidad, diagnóstico provisional/final, sesiones recomendadas, estado y botón de emergencia configurable.
- **Tratamiento**: actividades, avance, recaídas, objetivos, notas del terapeuta y estado del ánimo (escala 1-10).
- **Estadísticas**: emociones positivas y negativas, tendencias semanales y emociones dominantes, con filtros por período (semanal, mensual, anual).
- **Exportar a PDF**: descarga del historial clínico en PDF.
